**Project Summary:**
For this guided project, dataquest.io has created a scenario where we are working for a company that builds free apps for English-speaking audiences on IOS and Android devices. The only way this company brings in profit is through user engagement with ad content in apps. Our goal is to analyze IOS/Android app datasets to determine what app features correspond to higher user engagement. 

**Key Findings:**
Our final app recommendation would be to design an app that allows people to engage with a well liked movie or book. For more details, reference the full project.

**Datasource:**
In this project we will work with two datasets: one with IOS device information and one with Android device information. The IOS dataset was collected in July of 2017 and can be found with [this link](https://www.kaggle.com/datasets/ramamet4/app-store-apple-data-set-10k-apps). The information is collected from the Apple Store. The Android dataset was collected in August of 2018 and can be found with [this link](https://www.kaggle.com/datasets/lava18/google-play-store-apps). The information is collected from the Google Play Store. 

**Tools Used:**
This project uses the coding language Python and the Python module csv.  

**How to Run the Notebook:**
To rerun this notebook, place the data file named ‘AppleStore.csv’ and ‘GooglePlayStore.csv’ into the same folder.
